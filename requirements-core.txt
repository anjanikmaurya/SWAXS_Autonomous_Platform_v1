# ─────────────────────────────────────────────────────────────────────────────
# requirements-core.txt — everything needed to RUN the platform, nothing else.
#
# Use this one. It installs on macOS, Windows and Linux from prebuilt wheels,
# so no compiler, no Qt, no CUDA, no OpenCL SDK. Typical install: 1-3 minutes.
#
#     pip install -r requirements-core.txt
#
# Why this file exists
# --------------------
# `requirements.txt` is a `pip freeze` of the original developer's Mac. It
# carries ~1 GB of packages the platform never imports — PyQt6, silx, pyopencl,
# sentence-transformers (which pulls torch), jupyter, debugpy — and several of
# them need a C compiler or an OpenCL SDK to build on Windows. That is what made
# installing on a colleague's Windows laptop painful. It was also *missing* four
# packages the code really does import.
#
# Version policy: minimum versions, not exact pins, so pip can pick the wheel
# that exists for the user's Python. Pin exactly only if a release breaks us.
# ─────────────────────────────────────────────────────────────────────────────
