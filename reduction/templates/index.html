Absolute calibration constant K
cm · (monitor units)⁻¹
Applied as: dΣ/dΩ (cm⁻¹) = K × counts / (Bstop × dcm)
Finding K: measure a primary standard under the same conditions, then K = Iref(q) / [counts(q) / (Bstop × dcm)] over a q range where the reference value is known.
 • Water: use the flat high-q plateau (~1.65 × 10⁻² cm⁻¹ at 25 °C).
 • Glassy carbon: use the beamline's absolute dΣ/dΩ curve (NIST SRM 3600 recommended).
Keep K = 1.0 for semi-absolute output (proportional to dΣ/dΩ, not calibrated).
I₀ and Bstop together is non-physical: Bstop ∝ Φ₀·T already contains the incident flux, so both double-count it. Use one.
What each mode computes
None: raw integrated counts, no correction
I(q) = counts(q)
Output in detector counts. For diagnostics, or when you apply all corrections elsewhere.
Bstop: divide by the transmitted-beam monitor
I(q) = counts(q) / Bstop
Bstop ∝ Φ₀·T (incident flux × transmission), so this corrects beam intensity and sample absorption in one step. Recommended default at SSRL. I(q) ∝ dΣ/dΩ × constant.
I₀: divide by the incident-beam monitor
I(q) = counts(q) / I₀
Corrects incident flux Φ₀ only; the result still carries the transmission T. Use when Bstop is missing or unreliable. Do not combine with Bstop or Absolute: both already contain Φ₀ (Bstop ∝ Φ₀·T).
Absolute: intensity in cm⁻¹
I(q) = counts(q) / (Bstop · dcm) ∝ dΣ/dΩ [cm⁻¹]
Since Bstop ∝ Φ₀·T, dividing by Bstop·d gives intensity proportional to the differential cross-section dΣ/dΩ (cm⁻¹). True absolute units need K from a primary standard (water or glassy carbon):
dΣ/dΩ (cm⁻¹) = K · counts(q) / (Bstop · dcm)
Already includes Bstop and I₀, so selecting Absolute deselects both.
