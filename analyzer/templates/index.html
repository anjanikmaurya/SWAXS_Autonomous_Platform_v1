▾ How the score works

Each measured recipe gets one score (lower is better): distance from the target size plus a spread penalty. The strategy uses it to pick the next recipe (see Acquisition under Search strategy).

  • Score (size error plus spread); one tolerance off the target counts as 1. score = ((R−Rt)/tol)² + w·(PDI/cap); You enter a diameter; Rt = diameter/2.
